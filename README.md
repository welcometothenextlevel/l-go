# L-GO — site de démonstration

Site statique multi-page pour l’auto-école L-GO, construit sans backend afin d’être compatible avec GitHub Pages.

## Développement

```bash
npm run build
npm run dev
```

Le site local est servi sur `http://127.0.0.1:4173/`.

Le calendrier, les formulaires et l’assistant sont des démonstrations front-end. Aucune donnée n’est transmise.
